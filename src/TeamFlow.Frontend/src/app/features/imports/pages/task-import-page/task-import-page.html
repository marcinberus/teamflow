Accepted formats

CSV — no header row. Each row has exactly five quoted fields:

"Title","Description","UserId","DueDate","Status"

JSON — a top-level array of objects with title, description, userId, dueDate and status.

Some values are replaced rather than rejected: an unknown status becomes Todo, a user who is not a project member becomes you, and an invalid due date becomes empty. Review the imported tasks afterwards.
